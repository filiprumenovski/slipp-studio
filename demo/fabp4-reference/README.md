# Apo FABP4 reference · PDB 1LIB

Mouse adipocyte fatty-acid binding protein (FABP4 / aP2), apo crystallographic coordinates at 1.70 Å. Source: https://www.rcsb.org/structure/1LIB ; coordinates downloaded unchanged from https://files.rcsb.org/download/1LIB.pdb . The asymmetric unit contains one protein chain plus waters and no bound lipid. This is not an expanded biological assembly.

The bundled six-pocket analysis was computed with the application's real fpocket + original SLiPP pipeline on protein heavy atoms. The original random-forest recipe is refitted from the published training data with seed 2026; these are uncalibrated model outputs, not validated binding probabilities. No docking runs are prepopulated. Exact coordinate/model/binary hashes and versions are retained in studio.json provenance. A known lipid-binding protein need not receive a high SLiPP score.

This archived FABP4 example remains a regression fixture. The Home reference now uses BstB (7T1M) from Dassama Lab; see ../lipid-reference/README.md.
